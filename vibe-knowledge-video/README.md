# Vibe 知识大赏 · Claude × 剪映 产出流程

> 目标：一个人、一台电脑，**每条视频 3～5 小时**，稳定产出「用 AI 把知识拍成大片」风格的 2～3 分钟知识短片，同时发 B 站和抖音。
>
> 分工：**Claude 负责选题、查证、文案、分镜，并写出生成画面的代码**；**剪映负责音乐、音效、字幕样式、封面和导出**。

```
选题 → 查证 → 文案(字幕稿) → 分镜表 → 代码出画面 → 渲染 MP4+SRT → 剪映(配乐/音效/字幕/封面) → 发布 → 复盘
 └──────────────── Claude（claude.ai 对话） ────────────────┘ └ Claude Code ┘   └──────── 剪映专业版 ────────┘
```

---

## 0. 先拆解对标：比特新语 在做什么

账号 [比特新语](https://space.bilibili.com/3494362707135250)（截至 2026-10 约 62 万粉）签名写的是：「用未曾见过的视听，讲未曾见过的故事。音乐与光影皆是引信……Vibe知识大赏：用 AI 把知识拍成大片。」热门作品的规律如下：

| 维度 | 观察到的规律 | 例子 |
|---|---|---|
| **时长** | 几乎都在 **2:40～2:50**，说明结构和配乐长度都是固定的 | 《银牌的眼泪》2:42、《剃刀》2:40、以牙还牙 2:42 |
| **选题公式** | **一个硬知识 × 一种普遍情绪**。知识来自数学、物理、经济学、心理学、信息论、AI，情绪落在遗憾、爱情、坚持、和解 | 香农信息论 × 「我爱你说到第 1000 遍」；反事实思维 × 「差一点」；最优停止 × 「37 法则」 |
| **时事** | 诺奖周连发两条，都破百万播放 | 光遗传学（生理学或医学奖）、冰立方中微子（物理学奖） |
| **标题** | 一个《两三字意象》，再接一句反常识或戳情绪的话 | 《银牌的眼泪》｜最痛的，不是失败，是"差一点"；两个一模一样的地方之间，是不会起风的 |
| **叙事骨架** | 生活钩子 → 年份、人物、实验 → 精确数字 → 用代码把实验**真跑一遍**并可视化 → 反转 → 升华 → 「致每一个……的人」 | 以牙还牙：「我们用代码把这场比赛真实重跑了一遍：15 个策略，120 场对局，24,000 个回合」 |
| **数字** | 大量精确、可以核实的数字，这是可信度和传播力的来源 | 「每秒 650 亿个中微子穿过你的指甲盖」「0.8⁵ = 33%」 |
| **视听** | **没有人声旁白**，靠音乐、光影和双语字幕推进；深色背景，有电影感 | — |
| **简介** | 把视频再讲一遍成小故事，补上定义和出处，并注明「本视频使用 Opus 制作……不是一句话生成」 | — |

还有一个细节：有 UP 主拆过这类视频的数据，**2 秒内约 1/3 的人划走，5 秒只剩 1/3，平均观看 11 秒**。所以**前 3 秒的钩子比后面所有内容都重要**。

> ⚠️ 只学结构和方法，**不要照搬它的选题、文案和画面**。这个赛道已经有大量跟风作品，同质化内容很难再起量。差异化建议见第 9 节。

## 1. 准备工作（一次性）

| 工具 | 用途 | 说明 |
|---|---|---|
| **Claude**（claude.ai，Pro 或以上） | 选题、查证、文案、分镜 | 打开联网搜索，查证环节要用 |
| **Claude Code** | 写画面代码、渲染 | 在 `template/` 目录启动，它会自动读取 `template/CLAUDE.md` 里的风格规范 |
| **Node.js 18+**、**ffmpeg** | 渲染 | 在 `template/` 里执行 `npm i` 和 `npx playwright install chromium`。没装 ffmpeg 时，`npm i` 会尝试装上 `ffmpeg-static` |
| **剪映专业版**（电脑版） | 后期 | 需要导入 SRT、踩点、关键帧，手机版不够用 |
| 字体 | 画面质感 | 免费可商用：思源宋体、思源黑体（Noto Serif/Sans SC），装好后重启浏览器 |

目录结构：

```
vibe-knowledge-video/
├── README.md            ← 本文件：完整流程
├── prompts.md           ← 每个环节直接复制给 Claude 的提示词
└── template/
    ├── CLAUDE.md        ← 给 Claude Code 的风格和代码规范
    ├── scene.html       ← 画面工程（每一帧都是 renderFrame(t) 的纯函数）
    ├── render.mjs       ← 逐帧渲染 → out/video.mp4 + subtitles.srt + shots.txt
    └── package.json
```

每做一个新视频，就把 `template/` 复制一份，比如 `episodes/2026-10-一点点/`。

## 2. 流程总览与时间预算

| # | 环节 | 工具 | 产出物 | 用时 |
|---|---|---|---|---|
| 1 | 选题 | Claude | 选定 1 个题目，附一句话卖点 | 15 分钟 |
| 2 | 查证 | Claude（联网） | 事实卡：数字、年份、人物，每条附出处 | 20 分钟 |
| 3 | 文案 | Claude | 字幕稿，30～40 句、约 160 秒，含英文 | 30 分钟 |
| 4 | 分镜 | Claude | 分镜表（时间、画面、动效、音效点） | 20 分钟 |
| 5 | 出画面 | Claude Code | `scene.html` | 60～120 分钟 |
| 6 | 渲染 | `npm run render` | `video.mp4`、`subtitles.srt`、`shots.txt` | 5 分钟 |
| 7 | 后期 | 剪映 | 成片和封面 | 40 分钟 |
| 8 | 发布 | B 站 / 抖音 | 标题、简介、标签 | 10 分钟 |
| 9 | 复盘 | 后台数据 | 下一条要改的 1 件事 | 10 分钟 |

所有提示词都在 **[prompts.md](./prompts.md)**，下面只讲每一步的要点。

## 3. 选题（prompts.md → P1）

- 用公式造题：**【一个能被画出来的知识点】×【一种人人有过的情绪】**。
- 选题池可以从这里找：
  - 经典实验或模型：囚徒困境、最优停止、香农熵、幂律、蝴蝶效应、贝叶斯、中心极限定理、热力学第二定律、群体智能、混沌、六度分隔……
  - 时事：诺奖周、天文事件、AI 大新闻、高考或考研季、节日。
  - 反直觉的数字，例如 1.01³⁶⁵、生日悖论 23 人、0.8⁵。
- 让 Claude 一次给 20 个，按「**能不能画出来 / 情绪强度 / 数字冲击力 / 有没有人做过**」四项打分，挑总分最高的。
- **能不能画出来**最重要：这类视频的画面全靠代码动画，抽象到画不出来的题目直接放弃。

## 4. 查证（P2）

- 每个数字、年份、人名、实验都要有出处，例如原始论文、诺奖官网、教科书。让 Claude 输出「事实卡」表格，标出**可信度**和**常见误传**。
- 拿不准的说法用「相传」「有研究认为」来写。比特新语写赌徒德·梅雷时也用了「相传」。
- 科学类内容出错，评论区会被攻陷，还可能被平台限流。这一步不要省。

## 5. 文案 / 字幕稿（P3）

这类视频**没有旁白，字幕就是文案**。规范：

- 总长 **150～170 秒**，**30～40 句**，每句**中文不超过 18 字**，停留 2.5～4.5 秒。
- 节奏按五幕写：

| 幕 | 时间 | 作用 |
|---|---|---|
| 钩子 | 0～8 秒 | 一个生活画面加一个反问，第一句就要让人想看第二句 |
| 引子 | 8～40 秒 | 年份、人物、实验，像讲故事一样展开 |
| 推演 | 40～110 秒 | 精确数字加「我们用代码重跑了一遍」，这是视觉高潮 |
| 反转 | 110～140 秒 | 知识翻过来照见人生 |
| 落点 | 140～165 秒 | 一句金句，加上「致每一个……的人」 |

- 每句配英文。双语字幕让画面更「高级」，也方便以后发海外平台。
- 输出格式直接写成 `scene.html` 里的 `SUBS` 数组，后面可以直接粘贴进去。

## 6. 分镜表（P4）

- 每个镜头写清：起止时间、画面描述、**动效**（出现、生长、粒子聚散、镜头推拉）、要可视化的**真实数据**、**音效点**（重音、whoosh、低频 boom）。
- 一条片子大约 **10～16 个镜头**，单个镜头 6～15 秒。
- 统一视觉语言：深色底、1～2 个强调色、衬线大标题、细线条、发光点、粒子、胶片颗粒。模板里的 `PALETTE` 和 `filmLook()` 已经定好。

## 7. 用 Claude Code 出画面（P5）

在新视频目录里启动 Claude Code。`template/CLAUDE.md` 已经写好规范，Claude 会照着做。

1. 把第 5 步的 `SUBS` 和第 6 步的分镜表粘给 Claude，让它**一次只实现 2～3 个镜头**。
2. 用浏览器打开 `scene.html` 预览：空格播放或暂停，← → 跳 1 秒。看完把问题反馈给 Claude，比如「镜头 3 的曲线出现太快，数字要更大」。
3. 全部镜头完成后，执行 `npm run preview`（半分辨率、15fps，很快）通看一遍节奏，再执行 `npm run render` 出正片。

要点：

- **画面是时间的纯函数**，不录屏，所以不会掉帧，也能单独重渲某一段（`node render.mjs --from 40 --to 60`）。
- **数据要真算**：模拟、统计、曲线都在代码里实时计算，不要画假图。这是这类视频最大的可信度来源，也可以写进简介当卖点。
- 想走得更远，可以参考社区开源的 Skill 和引擎，按技术栈挑一个：[vibe-knowledge-video](https://github.com/xiazhuo123456789/vibe-knowledge-video)、[concept-reel](https://github.com/Jogzh/concept-reel)、[vibe-knowledge-video-skill](https://github.com/LuZhong-Li/vibe-knowledge-video-skill)、[vibe-knowledge-award (Remotion)](https://github.com/Buffaiai/vibe-knowledge-award)、[vibe-video](https://github.com/buerivan/vibe-video)。

渲染完会得到：

```
out/video.mp4          无声 1920×1080 30fps 画面
out/subtitles.srt      双语字幕（中文一行、英文一行）
out/subtitles.zh.srt   纯中文字幕
out/shots.txt          每个镜头的切点时间，供剪映对着卡音效
```

## 8. 剪映后期（约 40 分钟）

**① 新建与导入**
- 新建草稿，设置比例 **16:9、1080P、30fps**，把 `video.mp4` 拖进主轨。
- 「文本」→「本地字幕」→「导入」，选 `subtitles.srt`。时间轴和代码里的设计完全一致，不用再识别字幕。

**② 字幕样式**（选中任意一条字幕，勾选「应用到全部字幕」）
- 中文：思源黑体或宋体，字号约 7，白色 90% 不透明度，**不要描边**，加轻微阴影。位置在画面下方 1/8。
- 想要中英文不同字号，可以分两次导入 `subtitles.zh.srt` 和英文版，各占一条轨道。
- 动画：入场「渐显」0.3 秒，出场「渐隐」0.3 秒。

**③ 配乐（决定 50% 的 vibe）**
- 选曲方向：氛围钢琴、cinematic、ambient、post-rock，**有一次明显的情绪爬升**。比特新语的时长固定在 2:42 左右，很可能是一首曲子贯穿全片。
- 来源：**剪映音乐库**（发抖音时版权最省心）。发 B 站建议用无版权或已授权的音乐，比如 B 站的「音频素材」、YouTube Audio Library、Pixabay Music。也可以让 Claude Code 用 WebAudio 合成 BGM，参考上面的开源项目。
- 选中音乐，执行「踩点」→「自动踩点」，再对照 `shots.txt` 把**镜头切点对齐到节拍**，让高潮镜头（推演段的数字爆发）落在音乐最强的位置。
- 开头 1 秒淡入，结尾 3 秒淡出。

**④ 音效**（每条 10～20 个，宁少勿滥）
- 剪映「音频」→「音效」：搜 `whoosh`（转场）、`低音 boom` / `impact`（数字揭晓）、`打字` / `滴答`（数据跳动）、`钢琴单音`（结尾金句）、`环境底噪`。
- 音量：音乐 −18～−14 dB，音效 −12～−8 dB。人声没有，所以音乐可以比常规片子大一点。

**⑤ 画面微调**（可选）
- 滤镜「胶片」类，强度 20～30%。代码里已经有颗粒和暗角，不要叠太重。
- 结尾留 2 秒黑场，加账号签名或「致每一个……的人」。

**⑥ 封面**
- 「封面」→ 选高潮帧 → 加大字标题（就是《意象词》加一句钩子），**手机缩略图尺寸下也要能看清**。
- B 站封面用 16:9。抖音另外做一张 3:4。

**⑦ 导出**
- 1080P、30fps、码率选「更高」，格式 MP4（H.264）。
- 抖音竖屏版（可选）：复制草稿，画布改成 9:16，主画面居中，上下用「背景填充」→「模糊」，上方加大标题。原片按 16:9 横屏发也完全可以，对标账号就是横屏。

## 9. 发布（P6）

- **标题**：《意象词》｜反常识一句话，例如「《一点点》｜差距不在某一天，在每一天」。
- **简介**：把视频再讲成 150～300 字的小故事，加上关键定义和出处，最后写「本视频画面由 AI（Claude）编写代码生成」。
- **AI 标识（必做）**：按照《人工智能生成合成内容标识办法》（2025-09-01 起施行）和平台规则，B 站投稿和抖音发布时都要**勾选「AI 生成内容」声明**。不标识可能被限流甚至下架。
- **标签**：`#vibe知识大赏` 加上学科标签（`#数学思维` `#心理学` `#物理`）和情绪标签（`#治愈系短片` `#人生哲学`）。
- **分区**：B 站选「知识 → 科学科普」或「人文历史」。
- **时间**：工作日 19～22 点；遇到时事热点（诺奖公布当天）要抢在 24 小时内。
- **差异化**（避免和大量跟风号同质化）：
  1. 固定一个**你自己的视觉签名**，比如统一配色、片头 1 秒标识、固定结尾句式。
  2. 深耕一个**垂类**，例如只做「经济学 × 感情」或「物理 × 城市生活」，形成系列。
  3. 每期都做一个**真跑的模拟**，并在简介里写清参数，比如「我们跑了 10 万次」，这是最难被抄的部分。

## 10. 复盘（每条都做，10 分钟）

| 指标 | 在哪看 | 健康线（参考） | 不达标先改什么 |
|---|---|---|---|
| 3 秒留存 | 抖音创作者中心 / B 站稿件数据 | > 65% | 第一句字幕和第一个画面 |
| 完播率 | 同上 | > 25%（2 分 40 秒的片子） | 推演段太长、节奏太平 |
| 互动率（赞+评+藏）/ 播放 | 同上 | > 5% | 结尾升华和金句 |
| 涨粉 / 播放 | 同上 | > 0.5% | 系列感和视觉签名 |

把每条的数据和「下一条要改的 1 件事」记成一行表格。积累 10 条之后，把表格交给 Claude，让它总结哪种选题和钩子最有效（见 P7）。

- [ ] 字幕 30～40 句、单句 ≤ 18 字，总长 150～170 秒

- [ ] 音乐高潮对齐推演段，切点对齐节拍
