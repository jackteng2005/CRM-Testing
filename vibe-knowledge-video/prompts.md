# 提示词库（直接复制给 Claude）

用法：P1～P4、P6、P7 在 **claude.ai 对话**里用，P2 需要打开联网搜索；P5 在 **Claude Code** 里用。
`【】` 里的内容替换成你自己的。**同一条视频的 P1→P4 放在同一个对话里做**，Claude 会记住前面的结论。

---

## P1 · 选题

```
你是一位擅长「Vibe 知识大赏」风格的知识短片策划。这类视频的特点是：没有旁白，只有音乐、光影和双语字幕，
画面全部由代码生成（Canvas 动画、数据可视化、粒子），时长约 2 分 40 秒，
用「一个硬知识 × 一种普遍情绪」的公式，把知识讲成一部有情绪落点的小电影。
成功案例：香农信息论 ×「我爱你说到第 1000 遍信息量几乎为零」；反事实思维 ×「最痛的不是失败，是差一点」；
最优停止 ×「37 法则」；古德哈特定律 ×「刷分的捷径」。

我的账号定位：【例如：经济学 × 年轻人的感情和选择】
近期热点（可选）：【例如：诺奖周 / 高考 / 某个 AI 新闻】

请给我 20 个选题，用表格输出，列为：
序号 | 知识点 | 情绪 | 《两三字意象标题》 | 一句话钩子（≤20字） | 核心精确数字 | 可视化方案（用代码怎么画）|
能否画出来(1-5) | 情绪强度(1-5) | 数字冲击力(1-5) | 撞题风险(1-5，越高越常见) | 总分
总分 = 前三项之和 − 撞题风险。按总分排序，最后推荐 3 个并说明理由。
避开已经被大量做过的：沉没成本、幸存者偏差、熵增、37 法则、曝光效应。
```

## P2 · 查证（打开联网搜索）

```
选题定为：【知识点 + 标题】。
请联网查证，输出一张「事实卡」表格：
事实/数字 | 准确表述 | 出处（论文/官网/权威教材，附链接）| 可信度（高/中/低）| 常见误传
要求：
1. 涵盖所有可能出现在视频里的年份、人名、实验设计、实验结果、关键数字。
2. 能用代码复现的结论（概率、模拟、公式）请给出计算方法和参数，后面我会真跑一遍。
3. 有争议或存在复现危机的说法单独列出，并给出稳妥的写法（例如「相传」「有研究认为」）。
4. 最后列出 3 个可以写进简介的「冷知识彩蛋」。
```

## P3 · 文案 / 字幕稿

```
根据上面的事实卡写字幕稿。这类视频没有旁白，字幕就是全部文案。
硬性规范：
- 总时长 150–170 秒，30–40 句；每句中文 ≤ 18 字，停留 2.5–4.5 秒，句间留 0.3–0.5 秒空隙。
- 五幕结构：钩子(0–8s，一个生活画面加一个反问) → 引子(8–40s，年份、人物、实验) →
  推演(40–110s，精确数字加「我们用代码重跑了一遍」) → 反转(110–140s，知识照见人生) →
  落点(140–165s，金句加「致每一个……的人」)。
- 第一句 ≤ 12 字，必须让人想看第二句。
- 语言克制、诗意、具体；少用形容词，多用画面和数字；不说教，不用「你知道吗」「今天我们来聊」。
- 每句配一行地道简洁的英文。
- 只能使用事实卡中可信度为「高」或「中」的内容。

输出两部分：
A. 按幕分段的纯文本稿，方便我读一遍改语感；
B. 可以直接粘进 scene.html 的 JS 数组：
const SUBS = [ { start: 0.6, end: 4.2, zh: '…', en: '…' }, … ];
```

## P4 · 分镜表

```
根据字幕稿做分镜表，10–16 个镜头，用表格输出：
镜头 | 起止时间(s) | 对应字幕序号 | 画面描述 | 动效（出现/生长/粒子聚散/推拉/数字滚动…）|
需要实时计算的数据（写清公式或模拟参数）| 音效点（时间 + 类型：whoosh/boom/滴答/钢琴单音）| 情绪强度(1–5)

视觉规范：16:9、1920×1080；深色底(#07080c)；主色米白(#f2efe8)、强调金(#e8b45a)，
最多再加一个冷色(#5aa9e8)；衬线大标题；细线条、发光点、粒子、胶片颗粒；
不用照片和素材，全部由几何图形、文字、数据图形构成；每个镜头只讲一件事。
情绪强度要先升后收：推演段末尾达到 5，落点回到 2–3。
最后单独列出「音乐高潮应该落在第几秒」。
```

## P5 · 写画面代码（在 Claude Code 里用，目录为当前视频文件夹）

第一次：

```
读一下 CLAUDE.md 和 scene.html。下面是这条视频的字幕和分镜表。
先把 SUBS 换成我的字幕；然后只实现镜头 1–3，其余镜头先保留占位（只显示镜头编号）。
做完告诉我每个镜头里用了哪些真实计算。

【粘贴 P3-B 的 SUBS 数组】
【粘贴 P4 分镜表】
```

迭代（预览后反馈，越具体越好）：

```
镜头 3：曲线出现得太快，改成 6 秒内长完；终点数字放大到 64px，并在到达时闪一下光。
镜头 2 和 3 之间加一个 0.5 秒的交叉溶解。其他不要动。
```

收尾：

```
所有镜头完成了。请检查：1）每一帧是否只依赖 t（没有用 Math.random / Date.now）；
2）所有文字在 1920×1080 内不越界、不与字幕区（底部 160px）重叠；3）每个镜头首尾都有淡入淡出。
然后运行 npm run preview，并用 ffmpeg 每 10 秒抽一帧拼成图给我看。
```

## P6 · 发布文案

```
为这条视频写发布文案，分别给 B 站和抖音：
1. 标题 5 个备选：格式「《意象词》｜一句反常识或戳情绪的话」，≤ 30 字；
2. 简介：把视频再讲成 150–300 字的小故事，加上关键定义和出处，结尾写「本视频画面由 AI（Claude）编写代码生成」；
3. 标签 10 个：#vibe知识大赏 + 学科标签 + 情绪标签；
4. 封面大字 3 个备选（≤ 8 字）；
5. 置顶评论 1 条：抛一个能引发讨论的开放问题。
```

给出下一批 5 个选题（沿用 P1 的表格格式），以及 3 条可以执行的改进。
