# Vibe 知识大赏 · 画面工程规范

这个目录是一条知识短片的画面工程。`scene.html` 用 Canvas 画出每一帧，`render.mjs` 逐帧渲染成无声 MP4 和 SRT。
配乐、音效和字幕样式在剪映里做，**这里不处理声音**。

## 你要改的
- `scene.html` 里的 `SUBS`（字幕）和 `SHOTS`（镜头）两块。必要时可以在「引擎」区追加通用的绘图辅助函数。
- 不要改 `renderFrame` 的签名，也不要改 `window.__vibe` 的导出结构，`render.mjs` 依赖它们。

## 硬性规则
1. **每一帧都是 t 的纯函数**：不用 `Math.random()`、`Date.now()`、`performance.now()`，也不在帧之间累积状态。
   需要随机数就用 `rng(seed)`；需要模拟（博弈、粒子、随机游走），就在镜头外**预先算好整段结果**存进数组，绘制时按 t 取值。
2. **数据要真算**：曲线、统计、概率、模拟结果都要来自真实计算，不能手写假数值。在代码注释里写清公式和参数。
3. 画布固定 1920×1080、30fps。画面元素不要进入底部 160px 的字幕区（字幕由剪映导入 SRT 显示）。
4. 每个镜头首尾都有淡入淡出（用 `fade()`），镜头之间不能硬切到全黑以外的画面。
5. 不加载外部图片、视频或网络资源，只用几何图形、文字和数据图形。

## 视觉语言
- 颜色只用 `PALETTE`：深色底、米白主文字、金色强调，最多再加一个冷色。一个镜头最多 2 种强调色。
- 标题用 `FONT_SERIF`（大号、适度字间距），数据和注释用 `FONT_SANS`。
- 常用质感：发光点 `glowDot`、细线条（1–2px）、粒子聚散、数字滚动、缓慢推拉（整体 `ctx.scale` 在 1.00–1.06 之间变化）。
- 动效用 `ease()`，避免线性运动；重要信息出现后至少停留 1.5 秒。
- 少即是多：一个镜头只讲一件事，画面留白不少于 40%。

## 工作方式
- 用户每次只要求实现 2–3 个镜头，没提到的镜头不要动。
- 改完后告诉用户：在浏览器打开 `scene.html` 预览（空格播放或暂停，← → 跳 1 秒），或运行 `npm run preview` 出低清版。
- 需要自查时，用 `node render.mjs --preview --from A --to B` 渲染片段，再用 ffmpeg 抽帧查看。
